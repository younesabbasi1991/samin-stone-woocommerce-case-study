# Curated code samples

These files are representative extracts from the private Samin Stone codebase. They are included for technical review and portfolio demonstration, not as a complete WordPress package.

## What is included

| Directory | What it demonstrates |
| --- | --- |
| `custom-core-plugin` | Small module-based plugin architecture, product taxonomies, secure term-image administration |
| `product-filtering` | Sanitized taxonomy/price filtering and responsive accessible filter interactions |
| `ajax-cart-sidebar` | WooCommerce fragments plus an accessible off-canvas mini-cart controller |
| `product-unit` | Product metadata carried through the product, cart, checkout, and order lifecycle |
| `product-carousel` | Reusable server-rendered product carousel consumed by homepage queries |
| `product-search` | Product-only WordPress search form compatible with WooCommerce archive results |

## Important limitations

- Namespace bootstrap files, theme setup, stylesheets, templates, media, and dependencies are intentionally incomplete.
- The examples retain project-specific names so their relationship to the case study remains clear.
- WordPress and WooCommerce must already be loaded for the PHP examples to make sense.
- Some samples reference private template parts and CSS classes that are deliberately not published.
